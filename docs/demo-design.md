# 公安机关刑事案卷整理立卷训练 Demo

以“专业、安静、清晰”为视觉原则，采用深海军蓝、暖白纸色与少量黄铜金。页首居中呈现项目名与“吉警预审教学训练使用”，提供整理、校验成卷、成绩管理三项主导航。

工作台保持来源—图片—目录—去向四列顺序。四类来源筛选原始材料，图片可放大、多选、拖入目录，归卷不删除原材料，支持跨卷复用。目录自动编号，可拖拽、上下移动、删除。浏览器本地自动保存；提供清晰演示标识。

使用提供的74张原始图片、3张封面和21/37/18项答案。评分采用先过滤正确归类再比较相对顺序的最长公共子序列，最终率=顺序正确数/类别基数；这是Demo中对排序规则的明确解释，可按教师要求调整。≥60%启用成卷；封面、目录、材料按顺序在页内预览，无下载入口。三卷通过启用交卷，按30/50/20加权。

成绩页面展示当前浏览器产生的交卷记录，支持CSV导出。多学生身份认证、服务器集中成绩、真实AI问答均留待正式版本，Demo中不冒充已接入。

# 公安机关刑事案卷整理立卷训练

吉林警察学院预审教学训练交互 Demo。采用深蓝与暖金的工作台界面，将四类原始材料重新归入诉讼文书卷、证据材料卷和侦查工作卷。

## 已实现

- 74 份教学模拟材料、74 张缩略图、3 张卷宗封面及三套有序参考答案。
- 四类来源筛选、文件名搜索、多选添加、图片拖拽归卷和放大预览。
- 同一材料跨卷复用；卷内目录自动编号、拖拽排序、上下移动及删除。
- 当前浏览器自动保存整理进度，刷新页面后继续训练。
- 以 21 / 37 / 18 为基数校验，正确率达到 60% 启用成卷预览。
- 按“封面 → 生成目录 → 对应图片”逐页预览，不提供卷宗下载入口。
- 三卷通过后按 30 / 50 / 20 权重生成成绩，并可导出 CSV。
- 规则提示助手、演示进度载入和演示学员信息设置。

## 本地运行

这是无构建步骤的静态网页，不需要安装前端依赖。在项目目录运行：

```sh
python -m http.server 8931 --bind 127.0.0.1 --directory dist
```

使用浏览器打开 `http://127.0.0.1:8931`。推荐电脑宽屏体验；小屏工作台支持横向滚动。点击“载入演示进度”可以快速查看校验、成卷与评分流程。

## 验证

需要 Node.js 运行核心逻辑测试：

```sh
node --test tests/core.test.cjs
node --check dist/app.js
```

## Demo 范围与校验规则

本项目目前为浏览器本地演示，未接入真实身份认证、跨设备进度同步、教师端集中成绩服务或大模型接口。助手使用规则提示。成绩和训练进度保存在浏览器 `localStorage` 中，清理浏览器数据后会丢失。

校验先剔除不属于当前卷宗的材料，再通过最长公共子序列统计符合参考答案相对顺序的正确项，最终正确率为“顺序正确项 / 本卷基数”。因此，缺件不会让后续材料全部错位。此排序口径为 Demo 的明确解释，正式教学使用时应由教师确认。

正式考试需要在服务端保存身份、目录和成绩并重新校验，不能将浏览器本地记录作为可信成绩来源。页内预览无卷宗下载入口，但静态客户端不能提供严格的防复制保证。

## 教学素材

仓库包含用户提供的教学模拟材料及配套参考答案，用于该训练项目。未附加开源授权；素材的进一步分发与使用范围由权利人决定。原始 RAR、未压缩源资料和学生导出成绩不在本项目仓库内。

`.openai/hosting.json` 含现有站点的项目标识，不含访问凭据。复制项目建立独立部署时，应替换为新部署的配置。
